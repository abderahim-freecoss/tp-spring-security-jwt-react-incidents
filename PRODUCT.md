# Suivi des incidents
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Stack imposée par le TP : Spring Boot, Spring Security, JWT, JPA, React et Axios. H2 retenu pour le démarrage local.

## Utilisateurs et tâches
Employés : déclarer et suivre leurs incidents. Techniciens : traiter les incidents affectés. Administrateurs : gérer les utilisateurs et affectations.

## Première étape
Inscription EMPLOYEE, connexion, session protégée, consultation et modification du profil. Le reste du TP sera réalisé par étapes explicites.

## Contraintes confirmées
Interface sobre en français, centrée sur les formulaires (réponse utilisateur). Contrôles backend obligatoires, trois rôles, JWT de cinq minutes. Aucune identité graphique existante.
