# Interface de la première étape

Formulaires sobres en français, conformément au choix utilisateur. Construction directement en code.
Les écrans couvrent Login, Register et Profile ; aucun tableau de bord fictif.

- Fond : `#f4f6f3`, papier `#ffffff`, texte `#20312e`.
- Action principale : `#245b4a`, texte secondaire `#56655f`, bordure `#c4cec6`.
- Erreur : `#8c2823` sur `#fff3ef`, focus : `#b16a20`.
- Typographie de formulaire : Segoe UI, repli sans-serif. Corps 16 px.
- Champs et boutons : hauteur minimale 46 px, libellés visibles et focus clavier.
- Largeur de travail : 1040 px ; formulaire isolé : 480 px.
- Deux colonnes sur écran large, une colonne sous 700 px.
- États prévus : attente, erreur réseau, validation, succès, session expirée, page absente.
